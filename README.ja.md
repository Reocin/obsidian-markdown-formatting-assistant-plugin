## インストール

Obsidian で `設定 → コミュニティプラグイン` を開き、**閲覧** を選んで *Markdown Formatting Assistant* を検索し、**インストール**、**有効化** の順に押します。

手動でインストールする場合は、[最新リリース](https://github.com/Reocin/obsidian-markdown-formatting-assistant-plugin/releases/latest) から `main.js`、`manifest.json`、`styles.css` をダウンロードして `<vault>/.obsidian/plugins/obsidian-markdown-formatting-assistant-plugin/` に置き、プラグインを有効にします。

## サイドパネル

左側のリボンのアイコンか、コマンド *Markdown Formatting Assistant を開く* で開きます。このコマンドにはほかのコマンドと同じようにホットキーを割り当てられます。パネルは右サイドバーに開きます。設定の `サイドパネルの位置` で左に移せます。変更したら、リボンのアイコンをもう一度押してください。

パネルはペインの幅に合わせて表示されるので、ペインをドラッグして広げたり狭めたりすると、ボタンの並びも組み直されます。モバイルでも動作します。

ボタンは、特に指定しなければ中央に揃います。設定の `パネルのボタンの配置` で左寄せか右寄せに変えられ、色見本、表のサイズ選択、各セクションの下のリンクも一緒に揃います。開いているパネルにもすぐに反映されます。

テキストを選択していると、書式ボタン（太字、タグ、コールアウトなど）は選択範囲を置き換えずに囲みます。何も選択していなければ、カーソル位置に挿入します。

### セクションの並べ替え

セクションはヘッダーをドラッグすると移動でき、矢印をクリックすると折りたためます。並び順と折りたたみの状態は記憶されます。使わないセクションは設定でオフにできます。

![サイドパネルでセクションのヘッダーをドラッグして位置を変えているところ](assets/OrderableAndExpandableRows.gif)

### テキスト編集

見出し H1〜H6、太字、斜体、下線、取り消し線、ハイライト、インラインコード、コードブロックと mermaid ブロック、リンク、内部リンク、画像、引用、そして箇条書き・番号付き・タスクの各リスト。すでにその見出しがある行で同じ見出しボタンを押すと、見出しが外れます。

引用とリストは行単位で働くので、選択を行のどこから始めたか、カーソルが行のどこにあるかは関係ありません。複数の行に部分的にかかる選択でも、それらの行すべてが変換されます。間の空行はそのまま残り、引用の中に付けた箇条書きの記号は `>` の前ではなく後ろに入ります。同じボタンをもう一度押すと記号が外れます。

### 表

グリッドからサイズを選ぶと（ヘッダーを含めて最大 6 行 × 6 列）、ソース上で列が揃った状態の表が挿入されます。グリッドの下の配置ボタンで区切り行をなし・左寄せ・中央・右寄せに設定でき、選んだ配置は次の表にも引き継がれます。

行の途中に挿入した表は独立した行に移り、カーソルの後ろにあった文字列は最終行にくっつかずに表の下へ送られます。

![サイドパネルのテキスト編集セクションと表セクション](assets/panel-text-edit-tables.png)

### HTML

`<a>` `<abbr>` `<b>` `<br/>` `<center>` `<details>` `<dfn>` `<div>` `<em>` `<font>` `<hr/>` `<i>` `<img>` `<kbd>` `<mark>` `<p>` `<pre>` `<span>` `<strong>` `<sub>` `<summary>` `<sup>` `<table>` `<tbody>` `<td>` `<tfoot>` `<th>` `<thead>` `<tr>` `<u>`

タグではないものの、Obsidian に対応する Markdown がないため HTML で書くものが 2 つあります。PDF 書き出し用の**改ページ**と、**テキストの配置**（左寄せ、中央揃え、右寄せ、両端揃え）です。

![サイドパネルの HTML セクション](assets/panel-html.png)

### LaTeX

> LaTeX は数式（`$...$` または `$$...$$`）の中でしか機能しません。

演算子は 69 個あります。パネルに並ぶ 33 個はよく使うものです：分数、べき乗と添字、`\sqrt`、`\sum`、`\int`、`\prod`、`\lim`、`\partial`、`\infty`、三角関数、括弧。残りの 36 個（関係記号、集合と論理の記号、矢印、`\nabla`、`\binom`、`\overline`、黒板太字など）は `Alt+Q` のウィンドウにだけあり、名前で探せます。すべてをパネルに並べると、毎回記号の壁を端から読むことになるからです。

![サイドパネルの LaTeX セクション](assets/panel-latex.png)

### ギリシャ文字

> LaTeX と同じく、ギリシャ文字も数式の中でしか機能しません。

![サイドパネルのギリシャ文字セクション](assets/panel-greek.png)

### コールアウト

26 種類のコールアウトがあり、それぞれ対応する Obsidian のコールアウトブロックを挿入します。

見出しは表示言語で書き込まれるので、note は Obsidian の既定の英語表示ではなく `> [!note] ノート` となります。角括弧の中のキーワードは常に英語のままです。Obsidian はそれを見てアイコンと色を決めるからです。見出しを自分で入力したい場合は `コールアウトの見出しを書き込む` をオフにしてください。

選択したテキストはコールアウトの本文になり、複数の段落にわたる選択もコールアウトの中に収まります。引用記号がすべての行に付くためです。

![サイドパネルのコールアウトセクション](assets/panel-callouts.png)

## 検索ウィンドウ

`Alt+Q` を押すと、テキスト編集、HTML、LaTeX、ギリシャ文字の各セクションにあるすべてのスニペット（約 160 個）を検索するウィンドウが開きます。名前を数文字入力して Enter を押すだけです。カーソルがどこにあっても、テキストを選択していてもいなくても使えるので、手をキーボードから離さずに済みます。名前は表示言語でも英語でも一致するので、`warning` でも `警告` でも同じものが見つかります。

`Alt+C` はコールアウト用の同じウィンドウです。

表と色はパネルからのみ使えます。

![Alt+Q のウィンドウで数文字入力し、候補を挿入しているところ](assets/Suggestion_Window_How_to_use_with_hotkey.gif)

どちらのキーも `設定 → ホットキー` で変更できます。*コマンド選択を開く* または *コールアウト選択を開く* を検索してください。

![Obsidian のホットキー設定で Alt+Q のホットキーを変更しているところ](assets/Suggestion_Window_change_hot_key.gif)

## 個々のコマンドのホットキー

テキスト編集のすべての操作とすべてのコールアウトは Obsidian のコマンドとして登録されているので、`設定 → ホットキー` でどれにでもキーを割り当てられます。プラグイン名で検索すると一覧がすべて表示されます。初期状態で割り当てられているのは `Alt+Q` と `Alt+C` だけなので、既存のショートカットが奪われることはありません。

対象は、見出し、太字、斜体、下線、取り消し線、ハイライト、インラインコード、コードブロックと mermaid ブロック、リンク、画像、引用、3 種類のリスト、そして 26 種類のコールアウトです。`H1` に `Cmd+1`、`H2` に `Cmd+2` を割り当てるのがよくある設定です。

サイドパネル自体にもコマンドがあるので、リボンのアイコンに手を伸ばさなくても開けます。

HTML、LaTeX、ギリシャ文字の各セクションは意図的に対象外にしています。これらを合わせるとさらに 138 項目あり、ホットキーの一覧は `\alpha` を探すのに向いた場所ではありません。向いているのは `Alt+Q` のウィンドウで、そこではこれらすべてを検索できます。

## ノート上部のツールバー

エディタの上部に並ぶボタンの列で、これがあればサイドパネルを閉じたままにできます。ノートの領域を一段分使うため、`設定 → Markdown Formatting Assistant → ノート上部のツールバー` でオンにするまではオフになっています。

ボタンの中身は Obsidian のコマンドそのものです。だからこそ、この列は自分で組み立てる価値があります。Obsidian 自身のものも、このプラグインのものも、他のプラグインのものも、保管庫の**どの**コマンドでも置けます。検索欄から追加し、行をドラッグして作業の順に並べ、押さないものは外してください。

最初は日常的な書式が入っています：見出し、太字、斜体、取り消し線、ハイライト、インラインコード、引用、3 種類のリスト、リンク。この組み合わせに特別な意味はないので、全部消して自分だけの列を作ってかまいません。

ボタンは列の左寄せ、中央、右寄せのいずれかに置けます。普段視線がある位置に合わせて選んでください。

![ツールバーの設定：配置したコマンドの一覧、その配置、さらに追加するためのボタン](assets/settings-toolbar.png)

どのボタンもノートに書き込むので、ツールバーは編集中にだけ表示されます。また、スクロールではなく折り返すので、ペインが狭くてもボタンの半分が隠れることはなく、高さが一行分増えるだけです。

デスクトップ専用です。モバイルの Obsidian にはキーボードの上にツールバーがすでにあり、2 つ目は邪魔になるだけです。

> Obsidian はツールバーを置く場所を公開していないため、このツールバーはエディタ自身のコンテナに挿入しています。将来の Obsidian のリリースでツールバーの位置がずれたり消えたりしたら、まずここを確認してください。

## カラーピッカー

### 色を選ぶ

`色を選択` でカラーピッカーが開きます。閉じるとその色がすぐに使われ（選択範囲があればそこに、なければカーソル位置に）、クリップボードにもコピーされます。

`最近使った色` には、Obsidian を閉じるまで、直近に選んだ 10 色が残ります。`色を保存` を押すと現在の色が `保存した色` にずっと残ります。保存した色は設定でも編集できます。

色見本をクリックすると、その色をもう一度使えます。右クリックすると削除でき、保存した色はドラッグで並べ替えられます。

![最近使った色と保存した色が並ぶ、サイドパネルの色セクション](assets/panel-colors.png)

### 選択したテキストに色を付ける

テキストを選択して色（最近使った色、保存した色、新しく選んだ色のどれでも）をクリックすると、選択範囲がその色になるよう囲まれます。ワンクリックで済み、先にチェックしておくオプションはありません。

`background-color` にチェックを入れると、代わりに `<span>` で背景色が付きます。`<font>` タグで指定できるのは文字の色だけだからです。

### カラーコードを挿入する

**何も**選択していないときは、クリックでカーソル位置に何を書き込むかをチェックボックスで決めます。チェックボックスが表すのは、書きかけのタグに貼り付けるためのコード片です。そのため、選択範囲があるときには適用されません。「このテキストに色を付ける」の意味は一つしかないからです。

| チェックした項目 | カーソル位置に書き込まれる内容 |
| --- | --- |
| なし | `#ff0000` |
| `color` | `color: #ff0000` |
| `background-color` | `background-color: #ff0000` |
| 両方 | `color: #ff0000; background-color: #ff0000` |
| `style`（上のどちらかと一緒に） | `style="background-color: #ff0000"` |
| HTML | `<font color="#ff0000"></font>`（ほかに何をチェックしていても） |

## 言語

インターフェースは 12 言語に対応しています：English、Беларуская、Deutsch、Español、Français、Italiano、日本語、한국어、Português、Русский、Українська、简体中文。

既定では、Obsidian 本体に設定されている言語に従います。特定の言語を選ぶには `設定 → Markdown Formatting Assistant → 言語` を使います。Obsidian を再起動すると反映されます。

翻訳されるのは読むための部分だけです。`> [!note]` の中のコールアウトのキーワードは英語のままです。Obsidian はそれで判別するからです。検索ウィンドウでは、翻訳された名前と元の英語の名前のどちらでも一致します。

英語とロシア語以外の翻訳は、まだネイティブスピーカーの確認を受けていません。修正は大歓迎です。各言語は `src/locales/` 内の 1 つのファイルにまとまっており、新しい言語を追加するには、そのファイルを書いて `src/locales/index.ts` に 1 行加えるだけです。

## キーボードとスクリーンリーダー

`Tab` でサイドパネルのすべてのボタンに移動でき、`Enter` と `Space` で押せます。フォーカスのあるボタンには目に見える枠線が付きます。どのボタンにも名前があり、スクリーンリーダーが読み上げるほか、ホバー時にはツールチップとして表示されます。ほとんどのボタンは文字ではなく図柄なので、名前がなければ読み上げるものがありません。

## 設定

- **言語** — 既定値：Obsidian に合わせる。対応している 12 言語から選べます。再起動後に反映されます。
- **サイドパネルの位置** — 既定値：右。パネルを開くサイドバーです。
- **パネルのボタンの配置** — 既定値：中央。左寄せ・中央・右寄せから選べます。パネルの各セクションでボタンを寄せる位置で、色見本、表のサイズ選択、各セクションの下のリンクも一緒に揃います。すぐに反映されます。
- **コールアウトの見出しを書き込む** — 既定値：オン。コールアウトの名前を、選択した言語で見出しとして書き込みます。`[!note]` の中のキーワードはどちらの場合も英語のままです。
- **「*セクション名*」セクション** — 既定値：すべてオン。サイドパネルのどのセクションもオフにできます。再起動後に反映されます。
- **ノート上部のツールバー** — 既定値：オフ。どのコマンドをどの順に並べるか、ボタンを左寄せ・中央・右寄せのどれにするかを設定します。デスクトップ専用です。
- **保存した色** — 保存した色が、カラーピッカーの横に色見本として並びます。色を選ぶと追加され、色見本をクリックすると削除されます。この並び順が、パネルでの表示順になります。

## フィードバック

## 開発

```
npm install
npm run build
```

ビルド結果は `build/` に出力され、Obsidian に必要なもの（`main.js`、`manifest.json`、`styles.css`）がすべて揃います。試すには、これらを `<vault>/.obsidian/plugins/obsidian-markdown-formatting-assistant-plugin/` にコピーしてください。

```
npm test
npm run typecheck
```

テストは Node 自体の TypeScript サポートで動くので、テストフレームワークをインストールする必要はありません。Node 22.18 以降があれば十分です。テストの対象は、テキストとカーソル位置の計算、リストと引用の記号、色のマークアップ、12 個の翻訳ファイルの整合性、コードが使うクラス名とスタイルシートの突き合わせ、パネルのボタンのアクセシビリティ、そしてこのリポジトリへのリンクです。

ビルドに加えて `npm run typecheck` も実行してください。Rollup は `tsc` がエラーにするコードでもビルド成功と報告するので、ビルドが通っただけではほとんど意味がありません。

- **侧边栏**，包含七个板块，可以重新排序、折叠和关闭，按钮可靠左、居中或靠右排列。
- **`Alt+Q`** 按名称搜索约 160 个片段，用你的语言或英语都可以。**`Alt+C`** 对 26 种标注也是如此。
- **快捷键**：每个文本编辑操作和每种标注都可以绑定到你想要的任意按键。
- **笔记上方的工具栏**，默认关闭：可以放上库中的任何命令，顺序由你决定。
- **取色器**，一键为选中的文字上色，并记住最近使用和已保存的颜色。
- **12 种语言**，默认跟随 Obsidian 自身的语言。
- **可用键盘操作**，也支持屏幕阅读器。

由 [Reocin](https://github.com/Reocin) 编写，他于 2026 年移交了维护工作；0.5.0 及之后的版本由 Mark Karte 和 Claude 维护，仍在这个仓库中。

## 安装

在 Obsidian 中打开 `设置 → 第三方插件`，点击**浏览**，搜索 *Markdown Formatting Assistant*，然后点击**安装**和**启用**。

如需手动安装，从[最新发布版本](https://github.com/Reocin/obsidian-markdown-formatting-assistant-plugin/releases/latest)下载 `main.js`、`manifest.json` 和 `styles.css`，放到 `<vault>/.obsidian/plugins/obsidian-markdown-formatting-assistant-plugin/` 中，然后启用插件。

## 侧边栏

可以通过左侧功能区中的图标打开它，或者使用命令 *打开 Markdown Formatting Assistant*，这个命令和其他命令一样可以设置快捷键。它会在右侧边栏中打开；设置中的 `侧边栏位置` 可以把它移到左侧——更改后请再点击一次功能区图标。

面板会跟随所在窗格的宽度，所以把窗格拖宽或拖窄时，按钮网格会重新排列。在移动端同样可用。

除非你另作选择，按钮默认居中：设置中的 `面板按钮对齐` 可以让它们改为靠左或靠右排列——色块、表格选择器和每个板块下方的链接也会随之对齐。已打开的面板会立即更新。

选中文字时，格式按钮（粗体、标签、标注等）会把文字包裹起来，而不是替换它。没有选中内容时，它们会在光标处插入。

### 调整板块

拖动板块的标题栏可以移动它，点击箭头可以折叠它。顺序和折叠状态都会被记住。从不使用的板块可以在设置中关闭。

![在侧边栏中把板块标题栏拖到新位置](assets/OrderableAndExpandableRows.gif)

### 文本编辑

H1 到 H6 标题、粗体、斜体、下划线、删除线、高亮、行内代码、代码块和 mermaid 代码块、链接、内部链接、图片、引用，以及无序列表、有序列表和任务列表。在已经是该级标题的行上按下同一个标题按钮，会移除这个标题。

引用和列表按整行处理，所以选区从行内哪里开始、光标停在哪里都没有关系。选区覆盖多行中的一部分时，这些行都会被转换；中间的空行保持不变；在引用内添加的列表符号会放在 `>` 之后，而不是前面。再次按下同一个按钮会去掉这些标记。

### 表格

在网格中选择大小——最多 6 行 6 列，含表头——插入的表格在源码中各列已经对齐。网格下方的对齐按钮把分隔行设为无对齐、左对齐、居中或右对齐，这个选择会沿用到下一个表格。

在行中间插入的表格会移到单独的一行，光标后面的内容会被推到表格下方，而不是粘在最后一行上。

![侧边栏中的文本编辑和表格板块](assets/panel-text-edit-tables.png)

### HTML

`<a>` `<abbr>` `<b>` `<br/>` `<center>` `<details>` `<dfn>` `<div>` `<em>` `<font>` `<hr/>` `<i>` `<img>` `<kbd>` `<mark>` `<p>` `<pre>` `<span>` `<strong>` `<sub>` `<summary>` `<sup>` `<table>` `<tbody>` `<td>` `<tfoot>` `<th>` `<thead>` `<tr>` `<u>`

另有两项不是标签，但因为 Obsidian 没有对应的 Markdown 语法，所以用 HTML 书写：用于 PDF 导出的**分页符**，以及**文本对齐**——左对齐、居中、右对齐和两端对齐。

![侧边栏中的 HTML 板块](assets/panel-html.png)

### LaTeX

> LaTeX 只在公式中生效，即 `$...$` 或 `$$...$$` 之内。

共 69 个运算符。面板上的 33 个是日常常用的：分数、幂和下标、`\sqrt`、`\sum`、`\int`、`\prod`、`\lim`、`\partial`、`\infty`、三角函数和括号。其余 36 个——关系符号、集合与逻辑符号、箭头、`\nabla`、`\binom`、`\overline`、黑板粗体等——只在 `Alt+Q` 窗口中提供，可以按名称找到。如果面板把它们全部显示出来，每次都得从一整墙符号中逐个看过去。

![侧边栏中的 LaTeX 板块](assets/panel-latex.png)

### 希腊字母

> 与 LaTeX 一样，希腊字母也只在公式中生效。

![侧边栏中的希腊字母板块](assets/panel-greek.png)

### 标注

26 种标注类型，每种都会插入对应的 Obsidian 标注块。

标题会用你的界面语言写入，所以 note 标注写作 `> [!note] 笔记`，而不是显示 Obsidian 的英文默认标题。方括号里的关键字始终保持英文——Obsidian 正是靠它来确定图标和颜色。如果你更想自己输入标题，可以关闭 `写入标注标题`。

选中的文字会成为标注的正文，跨越多个段落的选区也会留在标注内：每一行都会重复引用标记。

![侧边栏中的标注板块](assets/panel-callouts.png)

## 搜索窗口

`Alt+Q` 会打开一个搜索窗口，覆盖文本编辑、HTML、LaTeX 和希腊字母板块中的所有片段——约 160 个。输入名称中的几个字母，然后按 Enter；无论光标在哪里、是否选中了文字都能使用，双手不必离开键盘。名称既能用界面语言匹配，也能用英语匹配，所以 `warning` 和 `警告` 找到的是同一项。

`Alt+C` 是针对标注的同样的窗口。

表格和颜色只能在面板中使用。

![在 Alt+Q 窗口中输入几个字母并插入建议项](assets/Suggestion_Window_How_to_use_with_hotkey.gif)

两个快捷键都可以在 `设置 → 快捷键` 中修改：搜索 *打开命令选择器* 或 *打开标注选择器*。

![在 Obsidian 的快捷键设置中修改 Alt+Q 快捷键](assets/Suggestion_Window_change_hot_key.gif)

## 单个命令的快捷键

每个文本编辑操作和每种标注都注册为 Obsidian 命令，因此可以在 `设置 → 快捷键` 中为其中任意一个绑定按键。搜索插件名称即可看到完整列表。除了 `Alt+Q` 和 `Alt+C`，默认不绑定任何按键，所以不会占用你已有的快捷键。

包括标题、粗体、斜体、下划线、删除线、高亮、行内代码、代码块和 mermaid 代码块、链接、图片、引用、三种列表以及 26 种标注。常见的设置是用 `Cmd+1` 对应 `H1`、`Cmd+2` 对应 `H2`。

侧边栏本身也有一个命令，所以不必去点功能区图标也能打开它。

HTML、LaTeX 和希腊字母板块是有意排除在外的。它们加起来还有 138 个条目，而快捷键列表并不是查找 `\alpha` 的好地方——`Alt+Q` 窗口才是，它能搜索所有这些条目。

## 笔记上方的工具栏

编辑器顶部的一排按钮，这样侧边栏就可以保持关闭。在你于 `设置 → Markdown Formatting Assistant → 笔记上方的工具栏` 中开启之前，它一直是关闭的，因为它会占去笔记的一条空间。

按钮就是一个 Obsidian 命令，仅此而已。正因如此，这一排按钮才值得花心思组合：库中的**任何**命令都可以放上去——Obsidian 自带的、本插件的、其他插件的都可以。用搜索框添加命令，拖动各行按你的工作顺序排列，再删掉你从来不点的那些。

初始内容是日常格式：标题、粗体、斜体、删除线、高亮、行内代码、引用、三种列表和链接。这组按钮没有什么特别之处；可以全部清空，搭建你自己的。

按钮可以放在这一行的左侧、中间或右侧——哪个位置顺着你的视线就放在哪里。

![工具栏设置：其中的命令列表、按钮的对齐方式，以及添加更多命令的按钮](assets/settings-toolbar.png)

工具栏只在编辑时显示，因为每个按钮都会写入笔记；它会换行而不是滚动，所以窗格较窄时只是多占一行高度，而不会藏起一半按钮。

仅限桌面端。在移动端，Obsidian 已经在键盘上方提供了工具栏，再加一个只会碍事。

> 工具栏被插入到编辑器自身的容器中，因为 Obsidian 没有公开可以放置工具栏的位置。如果将来某个 Obsidian 版本把它挪了位置或弄丢了，首先要检查的就是这里。

## 取色器

### 选择颜色

`选择颜色` 会打开取色器。关闭取色器时，颜色会立即被使用——有选区就作用于选区，没有就插入到光标处——同时也会复制到剪贴板。

`最近使用的颜色` 保存最近选过的 10 种颜色，直到关闭 Obsidian 为止。`保存颜色` 会把当前颜色永久保存到 `已保存的颜色` 中，这些颜色也可以在设置中编辑。

点击任意色块即可再次使用该颜色。右键点击色块可以删除它，拖动已保存的颜色可以调整顺序。

![侧边栏中的颜色板块，包含最近使用和已保存的颜色](assets/panel-colors.png)

### 为选中的文字上色

选中一些文字，点击一种颜色——最近使用的、已保存的或刚选的都行——选区就会被包裹起来，显示为该颜色。一次点击，无需先勾选任何选项。

勾选 `background-color` 则会改为设置背景色，用 `<span>` 实现，因为 `<font>` 标签只能设置文字颜色。

### 插入颜色代码

在**没有**选中任何内容时，复选框决定点击后在光标处写入什么。它们描述的是一段要粘贴到你正在编写的标签里的代码，所以在有选区时不起作用——“给这段文字上色”只有一种含义。

| 勾选项 | 在光标处写入 |
| --- | --- |
| 无 | `#ff0000` |
| `color` | `color: #ff0000` |
| `background-color` | `background-color: #ff0000` |
| 两者都勾选 | `color: #ff0000; background-color: #ff0000` |
| `style`，加上以上任意一项 | `style="background-color: #ff0000"` |
| HTML | `<font color="#ff0000"></font>`，无论还勾选了什么 |

## 语言

界面提供 12 种语言：English、Беларуская、Deutsch、Español、Français、Italiano、日本語、한국어、Português、Русский、Українська 和简体中文。

默认情况下，插件跟随 Obsidian 本身设置的语言。你可以在 `设置 → Markdown Formatting Assistant → 语言` 中指定一种语言；重启 Obsidian 后生效。

只有你读到的内容才会被翻译。`> [!note]` 中的标注关键字保持英文，因为 Obsidian 靠它来匹配。搜索窗口同时匹配翻译后的名称和英文原名。

除英语和俄语外，其他翻译尚未经过母语者审校——非常欢迎指正。每种语言都是 `src/locales/` 下的一个文件，新增一种语言只需编写这个文件，并在 `src/locales/index.ts` 中添加一行。

## 键盘与屏幕阅读器

`Tab` 可以到达侧边栏中的每个按钮，`Enter` 和 `Space` 可以按下它，获得焦点的按钮会显示明显的轮廓。每个按钮都有名称，屏幕阅读器会读出它，鼠标悬停时也会作为提示显示——大多数按钮上是图形而不是文字，没有名称的话就没有东西可读。

## 设置

- **语言**——默认：与 Obsidian 一致。可选 12 种支持语言中的任意一种。重启后生效。
- **侧边栏位置**——默认：右侧。面板在哪一侧的侧边栏中打开。
- **面板按钮对齐**——默认：居中。左对齐、居中或右对齐：面板各板块中按钮的位置，色块、表格选择器和各板块下方的链接也随之对齐。立即生效。
- **写入标注标题**——默认：开启。用你的语言把标注名称写作标题。无论开启与否，`[!note]` 中的关键字都保持英文。
- **「*板块名*」板块**——默认：全部开启。侧边栏的每个板块都可以关闭。重启后生效。
- **笔记上方的工具栏**——默认：关闭。设置工具栏上显示哪些命令、按什么顺序，以及靠左、居中还是靠右。仅限桌面端。
- **已保存的颜色**——以色块形式显示已保存的颜色，旁边是一个取色器。选择一种颜色即可添加，点击色块即可删除。这里的顺序就是面板中显示的顺序。

## 反馈

发现了 bug，或者缺少某个标签或运算符？请[提交 issue](https://github.com/Reocin/obsidian-markdown-formatting-assistant-plugin/issues)。面板上也有指向那里的链接。

## 开发

```
npm install
npm run build
```

构建产物位于 `build/`，包含 Obsidian 需要的全部文件：`main.js`、`manifest.json` 和 `styles.css`。把它们复制到 `<vault>/.obsidian/plugins/obsidian-markdown-formatting-assistant-plugin/` 即可试用。

```
npm test
npm run typecheck
```

测试直接使用 Node 自带的 TypeScript 支持运行，因此无需安装测试框架——Node 22.18 或更高版本即可。测试覆盖文本和光标位置的计算、列表和引用标记、颜色标记、十二个翻译文件的一致性、样式表与代码所用类名的对照、面板按钮的无障碍性，以及指向本仓库的链接。

除了构建，还要运行 `npm run typecheck`。对于 `tsc` 会拒绝的代码，Rollup 仍会报告构建成功，所以在这里，单看构建通过几乎说明不了什么。
